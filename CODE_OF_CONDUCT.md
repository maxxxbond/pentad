# Code of conduct

Pentad follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind and patient, assume good intent, criticise code rather than people, and keep discussions on topic.
Harassment, personal attacks and discriminatory language are not accepted in issues, pull requests, discussions or any other project space.

## Reporting

If someone's behaviour worries you, contact the maintainer privately through GitHub ([@maxxxbond](https://github.com/maxxxbond)), not in a public thread.
Reports are handled confidentially. The maintainer may edit or remove comments, close threads, and block people who break these rules.
