# Switching to Pentad

`pentad doctor` and `pentad setup` help you move from another shell or from separate notification and wallpaper daemons.

If you are switching from another shell (Waybar, AGS, illogical-impulse or any other Quickshell config), its start line has to go; `pentad doctor` names the processes that hold notifications, the wallpaper or the panels, and lists where they are started. `pentad setup` makes the switch for you, whatever the other shell is (illogical-impulse, Noctalia, DankMaterialShell, Caelestia, HyprPanel, AGS, Waybar, or a notification or wallpaper daemon): it writes Pentad's own `~/.config/hypr/pentad.lua` (or `pentad.conf`) with the start line and key bindings, adds one line to your entry file that loads it (`require("pentad")` through Hyprland's own config path, so a synced dotfiles folder keeps working elsewhere), comments out the other shell's start line when that line is a single plain start statement (`hl.exec_cmd("…")`, the one-line `hl.on("hyprland.start", …)` hook, or `exec-once = …`), masks a systemd user service that runs it, and hides an XDG autostart entry for it; everything else it lists for you to change. It shows the exact edits first and applies them only after you confirm. Then it lets Hyprland check the result: it asks for a config reload (`hyprctl reload`) and reads `hyprctl configerrors`, and if new errors appear it puts everything back on its own. Hyprland reloads on its own as well whenever one of its config files changes, and every reload runs the top-level code of a Lua config again, so a bare `hl.exec_cmd(...)` outside `hl.on("hyprland.start", ...)` runs once more. After a clean apply it offers, as a second question, to switch right now: stop the old shell and start Pentad through Hyprland. `pentad setup --undo` restores the files, unmasks the service and removes the autostart override; when you edited a file after setup, it undoes just its marked lines after showing you the diff.
