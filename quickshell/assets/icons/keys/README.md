Glyphs drawn on keycaps, tinted at runtime by PentadIcon: a 24 px grid, filled paths in symbolic black.

- `super-pentad-symbolic.svg`: the Pentad mark for the Super key, redrawn from `../brand/logo-symbolic.svg` for small sizes (a regular pentagon, the inner pieces merged into one, wider gaps). The Pentad marks are covered by `TRADEMARK.md`.
- `super-tux-symbolic.svg`: a penguin for the Super key, drawn for Pentad from scratch (not derived from Larry Ewing's Tux or an icon set); GPL-3.0-only with the rest of the project.
